# CADS-praktikum-docs

Oeffentlich zugaengliche Praktikumsaufgaben und Referenzdokumentation des
Rechnernetze-Praktikums. Automatisch aus dem privaten Repository
[scimbe/CADS-praktikum-creator](https://github.com/scimbe/CADS-praktikum-creator)
gespiegelt (nur `docs/labs/`, `docs/reference/`, `docs/index*.md` - keine
internen Architektur-Entscheidungsdokumente/ADRs, keine Infrastruktur-
oder Betriebsdetails).

Veroeffentlicht via GitHub Pages: https://scimbe.github.io/CADS-praktikum-docs/
